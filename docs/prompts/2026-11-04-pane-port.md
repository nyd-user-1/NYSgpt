## How trinity's pane works (so you port it faithfully)

The second panel is an iframe whose src is a route of the SAME app — a full App Router render inside it; the iframe is only the window. Src is set once per opening, the page navigates inside on its own, and the outer URL carries the pane in `?pane=` so it restores. Key files: `src/components/pane.tsx` (PaneFrame/PaneSync), `src/lib/pane.ts` (PANE_MAIN/PANE_MESSAGE/PANE_PARAM/isEmbedded/isPanePath), `src/components/shell.tsx` (~93–260: pane state, --split drag, sizes, openPane, headerMenu, the document contextmenu listener), `src/components/go-to-menu.tsx` (the Side type — menu drives whichever side it opened over; ⌥Enter/row-arrow sends to the other).
